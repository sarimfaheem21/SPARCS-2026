SCD Hospitalization & Utilization Surveillance: Draft Dashboard

An interactive draft dashboard characterizing sickle cell disease (SCD) across New York State, built from the SPARCS patient-year extract (2014–2024).

Live draft: [SPARCS 2026 ISEE BETA](https://sarimfaheem21.github.io/SPARCS-2026/)

What this is

A working prototype for ISEE Lab review. It pulls together five views of the SCD data including severity and mortality-risk trends, geographic distribution, demographics, and care utilization, all into a single interactive page. The goal at this stage is accessibility: stakeholders and admin can open the link on any device (phone, laptop, meeting-room screen) and click through a draft without needing a login, an install, or a BI-tool license.

What you can do in it
Drag the year range to filter the severity/mortality-risk trend
Click any county - on the map or in the list - to re-slice every view for that county
Click a point on the trend chart, or a county on the map, for detail
Notes
This is a draft. All figures reflect the current 2014–2024 extract and are provisional until a final data freeze.
The numbers shown are aggregate figures only: no patient-identifiable data appears anywhere.
Mortality risk is a coding-based (APR-DRG) proxy, not a linked death outcome.
Reference context: Iloegbu et al., JAMA Network Open 2026 (for context, not used as a data source).
Data

The aggregate figures behind the dashboard are also available as a spreadsheet (/data) so they can be taken into other tools.
